# Custom workouts

Open **Workouts → Create workout** after choosing a runner.

Give the workout a name and a maximum speed, then build up to 40 intervals.
Each interval has:

- A name, such as Run, Recovery or Cooldown.
- A duration in minutes or a distance in miles.
- A speed target in 0.1 mph increments and an incline target in 0.5% increments.
- Optional low/high heart-rate targets.

Running workouts use 2–10 mph and 0–3% incline. Hikes retain their separate
terrain limits. Use Duplicate interval for repeats, and Move up/down to reorder.
Save workout stores the template for the selected runner; it does not start the belt.
Edit, Duplicate and Delete are available on saved custom workouts. Deleting a
template does not remove completed history.

## Running the workout

Start the saved workout from Workouts. The existing three-second
countdown and 2 mph start apply. Your profile's optional five-minute warm-up
comes first and can be skipped. Interval time/distance excludes that warm-up
and pauses. Distance intervals use measured session distance.

Without HR guidance, the interval follows its speed/incline targets and does
not require a chest strap, including during the optional warm-up. Targets ramp
gradually: speed changes by at most 0.2 mph and incline by at most 0.5% per
command, with confirmation and a delay between adjustments. Interval time
includes these transitions; short intervals may end before a distant target
is reached.

If any interval uses HR guidance, connect a chest strap before starting.
For HR intervals, speed/incline entries are starting targets. The existing
10-second HR checks and settling periods adapt incline first, then speed up
to the workout's maximum. In-range HR can stop the initial ramp early. Lost HR
holds settings during HR-guided intervals; fixed intervals can still proceed
without HR. Manual adjustments hold until the next interval.

Switch to Plex after starting to use the existing floating workout controls.
Pause stops the belt and freezes progress. Finishing the final interval stops
the belt; choose End workout to save or discard. Saved sessions preserve the
executed workout snapshot even if you edit the template later. Garmin FIT
export includes distance-based steps, prescribed fixed speed, measured
samples and executed laps.
